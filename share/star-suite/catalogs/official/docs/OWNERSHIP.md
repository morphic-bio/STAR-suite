# Recipe ownership

| Artifact | Canonical home |
| --- | --- |
| Compiled STAR Suite algorithms and output semantics | `STAR-suite` |
| Reusable operational workflows and generic profiles | `STAR-suite-recipes` |
| MorPhiC dataset wrappers and delivery automation | `morphic-recipes` |
| Compact public reproducibility evidence | `STAR-suite-provenance` |
| Project run registries and collaborator handoff state | Project provenance repositories |

STAR Suite 1.7 keeps compatibility entries for previously built-in non-core
recipes. New recipe development occurs here. A later release can retire an old
entry only after callers have migrated to its namespace-qualified catalog ID.
