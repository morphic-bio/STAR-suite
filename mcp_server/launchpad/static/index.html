About STAR Launchpad

        

          STAR Launchpad is a browser helper that talks to the same workflow definitions as
          STAR MCP. Use Copy to paste the command into your
          terminal, or Run in shell (localhost only) to start the same command
          on the server host in the background.
        

        

          Load parameters / Save parameters read or write a
          JSON file via the browser file picker (client-side only). Format:
          { "workflow_id": "…", "params": { … } }
          or a flat object of parameter names to values.
        

        

          Quit server stops the STAR Server (Launchpad + MCP) running on this host.
          Shortcut: Ctrl+Shift+Q. Localhost only (for safety).
        

        

          By default the recipe list shows only basic STAR CLI workflows
          (star_*). Enable Include test & other recipes for
          UCSF production, E2E tests, and the rest (private entries appear on localhost).
        

        

          STAR Server hosts STAR MCP (for agents) and this UI on one port.
