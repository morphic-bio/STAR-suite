# Annotated score-first CR rescue validation, 2026-07-24

## Outcome

The CR genomic-multimapper path now has an explicit `annotated` evidence mode.
It implements the following deterministic contract:

1. Alignments without a retained, countable GTF gene do not participate and
   do not veto another alignment.
2. STAR alignment score is compared across the remaining per-alignment
   GeneFull evidence.
3. A higher-scoring intronic gene can win over a lower-scoring exonic gene,
   and vice versa.
4. Equal-best evidence for different genes, or a best alignment carrying more
   than one gene, remains unresolved.
5. Exonic/intronic class chooses a representative only after gene uniqueness.

This fixes the historical order dependency in which a mutable winner alignment
could be overwritten by a later alignment. It also withdraws the broader
`decoy` experiment: annotation-free alignments are not `NA` competitors.
`compatibility` remains the default and preserves the established exon-first
contract; `annotated` must be requested explicitly.

Feature commits validated here are:

- `4a2d819d1d1600528ce09598d8c2b604870681f3` — score-first policy,
  parameter contract, tests, and workflow switch.
- `61fd241664c31ba53fd112a7795aca9470e3d855` — distinguish absent evidence
  from contradictory evidence so that absent annotation is not a feature veto.
