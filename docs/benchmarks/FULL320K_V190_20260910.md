# STAR Suite 1.9.0: full 320K benchmark, 2026-09-10

Both authorized full-set runs finished successfully with **7,303,142,230 read
pairs each**, covering lanes L001–L004. They used the same clean-built
Chromap-enabled STAR 1.9.0 binary on `m6id.12xlarge` with 48 threads.
No STAR reference index was loaded, no alignment was performed, and no
BAM/SAM or per-read decision sidecar was written. These are full-set results;
the earlier 201.901-second result covered only L004.

## Runtime and memory

| Format | September 9 control (s) | 1.9.0 (s) | Wall-time reduction | Speedup | Peak RSS, control → new (GiB) |
| --- | ---: | ---: | ---: | ---: | ---: |
| CBQ | 1217.150 | **628.033** | **48.40%** | 1.938× | 138.852 → **103.968** |
| FASTQ-BGZF | 1452.071 | **867.680** | **40.25%** | 1.674× | 139.944 → **93.794** |

Wall time covers the complete STAR process, including input, counting, cell
calling, and output. The two runs were sequential. OS caches were dropped
before each timed arm. No archive compression, upload, build, or competing
benchmark ran on the instance during timing. The statistical comparison and
supplemental archive ran afterward. These are one execution per input arm,
without a confidence interval or repeated-run claim.

Saved Cyto 0.4.7 full-set controls from the same 48-thread instance are
**758.46 s for CBQ** (113.9 GiB RSS) and **1,191.57 s for ordinary gzip FASTQ**
(111.2 GiB RSS). Cyto was not rerun, and its ordinary-gzip timing must not be
labelled BGZF. Cyto source commit: `19fb9495dba09e0ec4da97ea4cc529ac0a5f1380`.

## Statistical and count validation

Both formats called **333,439 cells**. Validation compared the full raw MEX,
eight filtered sample MEX files, cell identities, feature axes, caller
diagnostics, sample summaries, and read classifications with the September 9
full-set control. Matrix comparisons ignore only MatrixMarket comment lines;
JSON caller comparisons ignore only the `mc_threads` execution setting.

The exact baseline comparison also establishes cross-format parity. Each raw
matrix contains 7,924,268 CB+TAG identities, 19,068 model features,
725,480,265 nonzero entries, and 1,310,330,528 UMIs. Filtered exports contain
18,129 allowed features; deprecated features remain available to the model.
The tag-aware caller uses 100,000 simulations, BH FDR 0.01, deterministic
quality tie ordering, the 500-UMI floor, and joint observed-tag occupancy.
The shared permit pool returned all 48 permits after each run.

control, its pooled Cell Ranger comparison remains **0.9739611109446625 cell
Jaccard**: 325,079 shared cells, 8,360 STAR-only, and 331 CR-only. This is
inherited from an exact output match, not a newly executed comparator.
